TRANSPARENCY

Contract controls disclosed openly.

Verified source

The token source / proxy implementation is publicly visible through Etherscan.

Capped supply

The contract enforces a maximum supply of 10,000 BVM. The owner-only mint function cannot push total supply above that cap.

Burnable

Holders can burn their own BVM. A burn reduces total supply; because minting is capped rather than permanently disabled, burning can create room below the 10,000 BVM cap that the owner could mint back up to the cap while ownership remains active.

Transfer pause

The current contract includes an owner-controlled transfer pause mechanism. This administrative control remains available until ownership is renounced.

No claim of an independent security audit is made on this website. Users should review the verified contract source and current on-chain state directly.
